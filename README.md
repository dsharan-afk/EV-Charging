# EV Charging

EV Charged is a React and Vite application for exploring EV charging stations,
vehicles, and bookings. The repository also contains two API implementations:
the Node.js service in `backend/` and the Java service in `backend-java/`.

## Frontend

Use Node.js 20 or newer. Install dependencies with `npm install`, start the
development server with `npm run dev`, and create a production build with
`npm run build`.

## Backends

Each backend has its own setup instructions:

- [Node.js backend](./backend/README.md)
- [Java backend](./backend-java/README.md)

The frontend and backend services are separate applications and must be
configured and started independently.
